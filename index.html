使用说明

首次生成需要下载 Python 运行时与依赖，可能需要数十秒。后续计算复用已加载的运行时。

选择图片 → 设置色彩空间与采样精度 → 生成可视化。修改参数后需要重新生成。低精度适合快速预览。

图片在浏览器后台线程处理。网页复用原有 Python 脚本；依赖下载需要网络连接，图片内容不会发送到服务器。
